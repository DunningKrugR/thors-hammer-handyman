### GitHub Pages Setup (when ready)

1. Create a GitHub repository (e.g. `thors-hammer-handyman`).
2. Push this folder's contents (`index.html`, images) to the repo.
3. Go to **Settings → Pages** → set source to `main` branch, root `/`.
4. Site will be live at `https://<username>.github.io/<repo-name>/`.
5. Under **Custom domain**, enter the purchased domain and follow GitHub's DNS instructions.
6. Enable **Enforce HTTPS** once DNS propagates.
